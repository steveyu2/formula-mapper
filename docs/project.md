# 项目说明：公式变量映射与可视化工具

## 1. 项目概述

本项目是一个单页面Web应用，旨在提供一个交互式图形界面，用于编辑和展示数学公式，并支持将公式中的英文变量映射为中文变量。核心功能包括：动态解析用户输入的英文公式和中文公式，按变量出现顺序建立映射关系；在图形界面中渲染公式，并支持鼠标悬停时显示英文变量对应的中文含义；同时，以树形结构可视化公式的解析过程（抽象语法树），增强对公式结构的理解。

### 1.1 核心目标

- 提供两个输入区域，分别用于编辑英文公式（如 `a+b+c*d`）和中文公式（如 `变量1+变量2+变量3*变量4`）。
- 自动提取两个公式中的所有变量，并按出现顺序建立一一对应的映射关系（例如 `a` → `变量1`, `b` → `变量2`）。
- 在图形界面中清晰显示英文公式，当鼠标悬停在公式中的变量（如 `a`）上时，弹出提示框显示其对应的中文变量文本（如 `变量1`）。
- 将英文公式解析为抽象语法树（AST），并以图形化的树形结构展示公式的组成过程，同样支持悬停显示变量映射信息。

## 2. 功能需求

### 2.1 输入与编辑
- **英文公式输入框**：允许用户输入包含英文字母（支持大小写，如 `a`, `price`, `x1`）和基本运算符（`+`, `-`, `*`, `/`）及括号 `(` `)` 的表达式。默认值：`a+b+c*d`。
- **中文公式输入框**：允许用户输入包含中文变量（连续汉字序列，如 `单价`, `数量`, `变量1`）和相同运算符及括号的表达式。默认值：`变量1+变量2+变量3*变量4`。
- **实时响应**：任一输入框内容变化时，立即重新计算变量映射，并更新公式显示区域和语法树可视化区域。

### 2.2 变量映射逻辑
- **变量提取**：
  - 英文公式：使用正则表达式 `/\b[A-Za-z][A-Za-z0-9]*\b/g` 提取所有变量（以字母开头，后跟字母或数字，避免提取数字和运算符）。
  - 中文公式：使用正则表达式 `/[\u4e00-\u9fa5]+/g` 提取所有连续汉字作为变量。
- **顺序映射**：按提取到的变量在公式中**首次出现**的顺序建立映射列表。例如：
  - 英文变量顺序：`[a, b, c, d]`
  - 中文变量顺序：`[变量1, 变量2, 变量3, 变量4]`
  - 结果映射：`a→变量1`, `b→变量2`, `c→变量3`, `d→变量4`。
- **数量不匹配处理**：若英文变量数量多于中文变量，多出的英文变量映射值为“（未定义）”；若中文变量数量更多，则忽略多余的中文变量，并在映射表中给出提示。
- **映射表展示**：在界面中以表格或列表形式清晰展示当前映射关系，便于用户确认。

### 2.3 公式显示与悬停提示
- **显示区域**：渲染并显示英文公式，保留原有运算符和括号格式。
- **变量高亮与悬停**：
  - 公式中的每个变量应被独立的HTML元素（如 `<span>`）包裹，并添加`title`属性（或自定义Tooltip）来展示其对应的中文变量文本。
  - 鼠标悬停时，浏览器默认的`title`提示框即可满足需求。
- **样式**：公式整体采用等宽或美观的数学字体，变量可用不同颜色或下划线稍作区分。

### 2.4 图形化显示公式过程（抽象语法树）
- **AST生成**：根据英文公式字符串，解析生成一棵二叉树结构的抽象语法树。每个节点代表一个变量（叶子节点）或一个运算符（内部节点）。
  - 支持运算符：`+`, `-`, `*`, `/`。
  - 支持括号改变优先级，遵循标准算术运算优先级（`*`/`/` 高于 `+`/`-`）。
- **树形可视化**：
  - 使用HTML/CSS（如Flexbox或网格）递归绘制树结构。
  - 内部节点显示运算符（如 `+`, `*`），叶子节点显示变量名（如 `a`）。
  - 每个节点（尤其是变量节点）同样支持鼠标悬停显示其对应的中文变量映射文本（使用`title`属性）。
- **动态更新**：英文公式变化时，重新生成AST并刷新树形视图。

## 3. 技术规格

### 3.1 技术栈
- **前端**：原生HTML5, CSS3, JavaScript (ES6+)
- **无外部依赖**：为确保简洁和可移植性，不使用任何第三方库（如React, Vue, MathJax等）。所有功能（表达式解析、AST生成、树形渲染）均需原生实现。
- **响应式布局**：界面应适配不同屏幕尺寸，在桌面浏览器上获得良好体验。

### 3.2 表达式解析器要求
- 实现一个健壮的表达式解析器，能够将中缀表达式转换为AST。
- 必须正确处理运算符优先级和括号。
- 示例算法：递归下降解析法或调度场算法（Shunting-yard）均可。
- 解析错误处理：当输入无效表达式（如括号不匹配、缺少操作数）时，应在界面合适位置显示错误提示，不影响页面其他功能。

### 3.3 AST数据结构
- 定义节点对象：
  - 变量节点：`{ type: 'variable', name: string }`
  - 运算符节点：`{ type: 'operator', operator: string, left: node, right: node }`
- 解析器需返回根节点，用于后续树渲染和表达式显示。

## 4. 界面布局设计

界面采用上下或左右分区的清晰布局，建议如下结构：
+--------------------------------------------------+
| [英文公式] a+b+c*d |
| [中文公式] 变量1+变量2+变量3*变量4 |
+--------------------------------------------------+
| 映射关系： a → 变量1, b → 变量2, ... |
+--------------------------------------------------+
| 公式展示区： |
| a + b + c * d |
| (每个字母可悬停显示对应中文) |
+--------------------------------------------------+
| 公式结构树（AST）： |
| + |
| / \ |
| + * |
| / \ / \ |
| a b c d |
| (每个节点可悬停显示映射) |
+--------------------------------------------------+

### 4.1 交互说明
- 输入框支持键盘编辑，实时更新所有区域。
- 映射表区域显示当前变量配对。
- 公式展示区应保持与输入相同的格式（空格可选保留）。
- AST树形区域应支持节点悬停提示，并提供适当的滚动或缩放（通过CSS overflow处理）。

## 5. 实现细节与关键点

### 5.1 变量映射的更新时机
- 监听两个输入框的`input`事件。
- 每次触发时，重新提取两个公式的变量列表，按顺序构建映射对象（Map或普通对象）。
- 更新映射表显示、公式展示区（重新生成带`title`的HTML）和AST树形视图（递归重新生成）。

### 5.2 公式展示区HTML生成
- 将英文公式字符串拆分为token（变量、运算符、括号）。
- 遍历token，若为变量，生成`<span class="formula-var" title="映射文本">变量名</span>`；否则生成文本节点。
- 拼接后插入展示容器，保留空白字符。

### 5.3 AST树形渲染
- 实现递归函数`renderASTNode(node, container)`，根据节点类型生成DOM元素。
- 变量节点显示变量名，添加`title`属性；运算符节点显示运算符。
- 通过CSS Flexbox实现树形排列（如左子树和右子树并排，父节点居中）。
- 对于深层树，允许容器自动换行或水平滚动。

### 5.4 错误处理
- 表达式解析失败时，在AST区域显示红色错误信息，公式展示区仍显示原始文本但禁用悬停映射（或保留之前的有效解析结果）。
- 输入框内容为空时，清空所有展示区域并给出提示。

## 6. 验收标准

1. 页面加载时，默认展示`a+b+c*d`和`变量1+变量2+变量3*变量4`，映射表正确显示`a→变量1`等，公式中悬停`a`显示“变量1”。
2. 修改英文公式中的变量（如将`a`改为`price`），中文公式中的变量（如`单价`），映射表按顺序更新（例如`price→单价`）。
3. 输入带括号和不同优先级的复杂表达式（如`(a+b)*c-d/e`），解析器正确处理，AST树结构符合运算逻辑。
4. 鼠标悬停在AST树中的变量节点上，同样显示对应的中文变量文本。
5. 输入非法表达式（如`a+*b`），AST区域显示错误提示，公式展示区正确显示原文本（或悬停无效），不引发控制台错误。
6. 界面布局美观，响应式良好，所有功能在Chrome、Firefox最新版上运行正常。

   - 中文: `最大值(变量1,变量2)+最小值(变量3,变量4)`

4. **带括号公式**: `(a+b)*c`
   - 中文: `(变量1+变量2)*变量3`

5. **幂运算公式**: `a^2+b^2`
   - 中文: `变量1的平方+变量2的平方`

#### 子公式
1. **子公式啊1**: `a+v`
   - 中文: `v+b`

#### 绑定关系
- 变量 `c` 绑定到公式 `33377`
- 变量 `g` 绑定到子公式 `啊1`
- 变量 `is` 和 `u` 绑定到同一公式 `33377`

## 🧪 核心测试流程

### 第一部分：公式解析测试 (PARSE-001 ~ PARSE-013)

#### 测试方法：

### 第二部分：公式计算测试 (CALC-001 ~ CALC-015)

#### CALC-001: 简单公式计算
1. 创建公式 `a+b`
2. 打开编辑弹窗，切换到"计算"Tab
3. 输入: a=1, b=2
4. **预期结果**: 
   - 计算过程: `1+2`
   - 最终结果: `3`

#### CALC-002: 复杂公式计算
1. 创建公式 `a+b*c/g*is*u`
2. 输入所有变量值
3. **预期结果**:
   - 显示完整计算过程
   - 结果正确

#### CALC-004: 变量绑定外部公式（重要）
1. 创建公式A: `a+b+c`（名称: 33377）
2. 创建公式B: `x+y+z`，将变量 `z` 绑定到公式 33377
3. 打开公式B的计算Tab
4. 输入:
   - 主公式变量: x=1, y=2
   - 绑定公式33377变量: a=3, b=4, c=5
5. **预期结果**:
   - 计算过程: `1+2+(3+4+5)`
   - 绑定公式计算: 3+4+5 = 12
   - 最终结果: 1+2+12 = 15

#### CALC-006: 多个变量绑定同一公式（关键测试）
1. 创建公式A: `a+a`（名称: 33377）
2. 创建公式B: `x+is+u`，将 `is` 和 `u` 都绑定到公式 33377
3. 打开公式B的计算Tab
4. 输入:
   - 主公式变量: x=1
   - 绑定公式33377（用于is）: a=11
   - 绑定公式33377（用于u）: a=12
5. **预期结果**:
   - is 和 u 的输入框独立，互不影响
   - is 计算: 11+11 = 22
   - u 计算: 12+12 = 24
   - 计算过程: `1+(11+11)+(12+12)`
   - 最终结果: 1+22+24 = 47

#### CALC-009: 绑定公式展开显示
1. 使用 CALC-004 的设置
2. **预期计算过程显示**:
   - 绑定公式被展开为完整表达式
   - 例如: `1+2+(3+4+5)` 而不是 `1+2+z`

#### CALC-011: 除零错误
1. 创建公式 `a/b`
2. 输入: a=10, b=0
3. **预期结果**:
   - 显示错误提示: "除数不能为零"
   - 不显示计算结果

## 🐛 常见问题排查

### 问题1: 计算结果不正确
**排查步骤**:
1. 检查变量是否全部输入
2. 检查绑定公式是否设置正确
3. 查看计算过程，确认变量替换正确
4. 检查绑定公式的值是否独立

### 问题2: 绑定公式值同步
**已知问题**: 已在最新版本修复
**验证方法**: 
- 多个变量绑定同一公式时
- 各自的输入框应该独立
- 修改一个不影响其他

### 问题3: 计算过程显示不完整
**排查步骤**:
1. 打开浏览器开发者工具
2. 查看 Console 日志
3. 检查 `boundFormulaExpressions` 是否为空
4. 检查绑定公式内容是否正确获取

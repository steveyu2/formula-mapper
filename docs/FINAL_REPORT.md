## 🔧 技术实现细节

### 1. 数据加载流程
```typescript
1. 用户访问页面
2. UniverSheet 组件挂载
3. 创建 Univer 实例（带完整样式）
4. 配置冻结、监听器等
5. 加载数据到表格
   - 设置表头（样式）
   - 填充数据行
   - 设置列宽和行高
6. 显示成功提示
```

### 2. Excel 导出流程
```typescript
1. 用户点击"导出 Excel"
2. 调用 exportToExcel()
3. 动态导入 ExcelJS
4. 创建 Workbook
5. 遍历 Sheets
   - 创建 Worksheet
   - 添加表头（样式）
   - 添加数据行
     - 序列化公式数据为 JSON
     - 设置单元格样式
6. 生成 Blob
7. 触发下载
```

### 3. JSON 导入流程
```typescript
1. 用户选择 JSON 文件
2. 调用 importFromJson()
3. 读取文件内容
4. 解析 JSON
5. 检测版本（V1/V2）
6. 根据版本解析数据
   - V1: 迁移旧格式
   - V2: 直接解析
7. 返回 SheetData[]
8. 更新页面状态
```

## 📝 已知问题和限制

### 1. 待优化功能
- ⏸️ **单元格点击事件** - Univer API 需要进一步研究
- ⏸️ **公式编辑器** - 双击编辑功能未实现
- ⏸️ **操作列按钮** - 查看/编辑/删除按钮未实现
- ⏸️ **分组行合并** - 多级分组合并单元格未实现
- ⏸️ **云端同步** - Cloudflare D1 集成未实现

### 2. 技术限制
- Univer 的 Facade API 文档不够完整
- 部分 API 仍在变化中（如 setFreeze 已弃用）
- 事件监听机制需要进一步探索

### 3. 性能考虑
- 大数据量（1000+ 行）可能需要虚拟滚动
- 公式解析缓存已实现，但 AST 缓存待开发
- 动态导入已用于 ExcelJS，减少初始包大小

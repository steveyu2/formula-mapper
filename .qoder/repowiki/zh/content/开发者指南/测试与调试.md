## 测试脚本与执行

### 命令行脚本
项目提供三种主要测试执行方式：

#### 基础测试执行
```bash
npm test
```
执行所有测试用例，生成测试报告。

#### 监视模式
```bash
npm run test:watch
```

#### 覆盖率测试
```bash
npm run test:coverage
```

生成代码覆盖率报告，包含HTML和文本格式。
